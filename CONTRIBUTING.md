# Contributing

Internal engineering repo for the KVMoonShot Chain exchange interface.

## Development

```bash
cp .env.example .env.local
npm install
npm run dev
```

## Before opening a PR

- `npm run typecheck`
- `npm test`
- `npm run lint`
- `npm run format:check`

## Branch naming

`feature/<ticket>-short-description` or `fix/<ticket>-short-description`
